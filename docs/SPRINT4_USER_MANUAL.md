# Sprint 4 - Manual do Usuario

## Objetivo
Este manual descreve como usar os recursos entregues no Sprint 4: dashboard executivo, analytics avancado e relatorios exportaveis.

## 1) Dashboard Executivo
- Acesse `Admin > Analytics > Executivo`.
- Use o seletor de periodo (`7d`, `30d`, `90d`) para filtrar os dados.
- Clique em `Atualizar` para forcar refresh das views materializadas.

### Alertas em tempo real
- A secao `Alertas em Tempo Real` mostra sinais de risco operacional:
  - satisfacao IA baixa,
  - custo operacional alto vs GMV,
  - baixo engajamento por condominio,
  - base IA sem uso.

## 2) Analytics Avancado
- Acesse `Admin > Analytics > Avancado`.
- Abas disponiveis:
  - `Funil de Conversao`
  - `Analise de Cohort`
  - `Retencao`

## 3) Relatorios
- Acesse `Admin > Relatorios`.
- Funcoes:
  - `Gerar Relatorio`: exportacao em PDF, Excel e CSV.
  - `Agendados`: configuracoes recorrentes.
  - `Historico`: downloads anteriores.

## 4) Boas praticas
- Use `30d` para visao operacional e `90d` para tendencia.
- Revise alertas diariamente.
- Gere relatorio mensal para fechamento.
